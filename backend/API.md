# API Документация: Каталог услуг

Базовый URL: `http://127.0.0.1:8000/api/`
Для всех запросов формат данных: `application/json`.
Пагинация: по 5 записей на страницу (параметр `?page=2` для перехода на следующую).

---

## 1. Категории (Categories)

**Базовый путь:** `/api/categories/`

*   `GET /api/categories/` — Список всех категорий (доступно всем).
*   `POST /api/categories/` — Создать категорию (только администратор).
*   `GET /api/categories/{id}/` — Детали категории (доступно всем).
*   `PATCH /api/categories/{id}/` — Обновить категорию (только администратор).
*   `DELETE /api/categories/{id}/` — Удалить категорию (только администратор).

### Дополнительный эндпоинт (п. 2.3):
*   `GET /api/categories/{id}/services/` — Список услуг выбранной категории (с пагинацией и фильтрацией).

---

## 2. Услуги (Services)

**Базовый путь:** `/api/services/`

*   `GET /api/services/` — Список услуг (публично видны только `is_available=True`, админ видит все).
*   `POST /api/services/` — Создать услугу (только администратор).
*   `GET /api/services/{id}/` — Детали услуги (включая название категории).
*   `PATCH /api/services/{id}/` — Обновить услугу (только администратор).
*   `DELETE /api/services/{id}/` — Удалить услугу (только администратор).

### Параметры фильтрации, поиска и сортировки:

**Фильтрация (django-filter):**
*   `?category=1` — фильтр по ID категории.
*   `?is_available=true` — фильтр по доступности (только админ увидит `false`).
*   `?min_price=1000` — минимальная цена (включительно).
*   `?max_price=2000` — максимальная цена (включительно).
*   *Составной фильтр:* `?category=1&min_price=500&max_price=1500`

**Поиск (SearchFilter):**
*   `?search=английский` — поиск по названию (`name`) и описанию (`description`).

**Сортировка (OrderingFilter):**
*   `?ordering=price` — сортировка по цене (по возрастанию).
*   `?ordering=-price` — сортировка по цене (по убыванию).

## 3. Заявки (Service Requests)

**Базовый путь:** `/api/requests/` *(уточни префикс в urls.py, обычно это requests или service-requests)*

*   `POST /api/requests/` — Создать заявку (доступно всем без авторизации). 
    *   *Обязательные поля:* `service` (ID), `client_name`, `phone`, `desired_at`.
    *   *Статус* (`status`) проставляется сервером автоматически (`new`).
    *   *Валидация:* дата должна быть в будущем, телефон не пустой, услуга должна быть доступна (`is_available=True`).
*   `GET /api/requests/` — Список заявок (только администратор).
*   `GET /api/requests/{id}/` — Детали заявки (только администратор).
*   `PATCH /api/requests/{id}/` — Изменить статус заявки (только администратор).
*   `DELETE /api/requests/{id}/` — Удалить заявку (только администратор).

---

## 4. Статистика (Дополнительное задание)

*   `GET /api/statistics/` — Получить статистику (только администратор).
    *   Возвращает количество услуг по категориям и число новых заявок за текущую неделю.

---

## Коды ответов (HTTP Status Codes)

*   `200 OK` — Успешный GET, PATCH, PUT.
*   `201 Created` — Успешное создание (POST).
*   `204 No Content` — Успешное удаление (DELETE).
*   `400 Bad Request` — Ошибка валидации (например, дата в прошлом или пустой телефон).
*   `401 Unauthorized` — Требуется авторизация.
*   `403 Forbidden` — Нет прав (например, аноним пытается изменить цену услуги).
*   `404 Not Found` — Объект не найден (например, несуществующий `service_id`).
